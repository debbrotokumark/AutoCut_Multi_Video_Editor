# AutoCut — ব্রাউজারে অটোমেটিক ভিডিও এডিটর

ব্যাকএন্ড নেই, বিল্ড নেই। শুধু স্ট্যাটিক ফাইল (HTML/CSS/JS), তাই সরাসরি **GitHub Pages**-এ চলে।
সব প্রসেসিং আপনার ব্রাউজারে (FFmpeg WebAssembly); কোনো ফাইল সার্ভারে যায় না।

## দুটো পেজ
| পেজ | কাজ |
|---|---|
| `index.html` — **ব্যাচ মোড** | অনেকগুলো (অডিও + ভিডিও) জোড়া দিন → সব অটো এডিট (প্যারালালে) → শেষ হলেই একটা একটা করে অটো ডাউনলোড |
| `editor.html` — ম্যানুয়াল এডিটর | একটা ভিডিও টাইমলাইনে দেখে হাতে ট্রিম/রিভার্স/মোড বদলানো |

## ব্যাচ মোড কীভাবে চালাবেন
1. প্রতিটি সারিতে **অডিও** ও **ভিডিও** দিন (বাছুন বা ড্রাগ করুন)। দুটো হলেই জোড়াটা লাইনে ঢুকে অটো শুরু হয়।
2. অনেক ফাইল থাকলে **📂 একসাথে অনেক ফাইল** চাপুন (বা পেজের যেকোনো জায়গায় ফেলুন)। ভিডিওগুলো ও অডিওগুলো আলাদা করে **নামের ক্রমে** (`1, 2, 10` — সংখ্যা ধরে) সাজিয়ে জোড়া লাগে: ভিডিও ১ ↔ অডিও ১, ভিডিও ২ ↔ অডিও ২…
3. কয়েকটা একসাথে রেন্ডার হয় (ডিফল্ট ২টা; বাঁ দিকের "প্যারালাল" থেকে ১–৪)। বাকিগুলো লাইনে অপেক্ষা করে।
4. চলার সময়েও নতুন জোড়া যোগ করা যায়, সেটা লাইনের শেষে যুক্ত হয়।
5. প্রতিটি শেষ হলেই `autocut-01-<অডিওর নাম>.mp4` নামে নিজে ডাউনলোড হয়। (অটো ডাউনলোড বন্ধ করা যায়; পরে "⬇ সব ডাউনলোড" আছে।)

> প্যারালাল মানে প্রতিটি জবের নিজস্ব FFmpeg ইঞ্জিন ও মেমোরি। RAM কম বা ভিডিও বড় হলে ১ বা ২ রাখুন। মোবাইলে ১ রাখাই ভালো।
> একসাথে অনেক ফাইল ডাউনলোডে Chrome একবার অনুমতি চাইবে — **Allow** দিন।

## ডিফল্ট সেটিং (সব ব্রাউজারে সেভ হয়)
- Main Audio ভলিউম **৩৫%**
- লোগো আকার **১৮%**, স্বচ্ছতা **৫৩%**, অবস্থান নিচে-বামে (৩% মার্জিন)
- লোগো একবার দিলেই ব্রাউজারে (IndexedDB) সেভ থাকে; ব্যাচ ও ম্যানুয়াল — দুই পেজেই নিজে বসে যায়। "সরান" চাপলে মুছে যায়।
- ব্যাকগ্রাউন্ড অডিও ব্যাচ মোডে নেই; ম্যানুয়াল এডিটরেও লুকানো।


## FFmpeg কোথা থেকে লোড হয়
- প্রথমে `vendor/ffmpeg/` (আপনার নিজের repo), না পেলে jsDelivr, তারপর unpkg (~31 MB, ব্রাউজার ক্যাশ করে; একবারই নামে, সব প্যারালাল জব শেয়ার করে)।
- নিজের repo-তে রাখতে চাইলে (অফলাইন/CDN ব্লক হলে): `./scripts/vendor-ffmpeg.sh` চালিয়ে `vendor/ffmpeg/` commit করুন।
- সিঙ্গেল-থ্রেড FFmpeg ব্যবহার হয়, তাই GitHub Pages-এ বিশেষ হেডার (COOP/COEP) লাগে না।

## এডিটের নিয়ম
- চূড়ান্ত দৈর্ঘ্য = মেইন অডিওর দৈর্ঘ্য।
- ভিডিও ছোট হলে ক্লিপ নরমাল → রিভার্স → নরমাল… এভাবে রিপিট; শেষ ক্লিপ প্রয়োজনমতো কাটা।
- রিভার্স অংশে মূল ভিডিওর সাউন্ড বন্ধ থাকে।
- আউটপুট ফ্রেমরেট = মূল ভিডিওর ফ্রেমরেট (১৫–৬০), রেজোলিউশন মূলের মতোই, অডিও AAC 192k।

## সীমাবদ্ধতা
- ব্রাউজারে FFmpeg ধীর। বড়/হাই-রেজোলিউশন ভিডিওতে "ড্রাফট" কোয়ালিটি চেষ্টা করুন। ডেস্কটপ Chrome/Edge/Firefox সবচেয়ে নিরাপদ।
- রেন্ডার চলাকালীন ট্যাব খোলা রাখুন (পেজ স্ক্রিন জাগিয়ে রাখার চেষ্টা করে)। পেজ রিফ্রেশ করলে কিউ মুছে যায়, তবে সেটিং ও লোগো থাকে।
- ভিডিও/অডিওর ফরম্যাট ব্রাউজারের ডিকোডারে খুলতে হবে (MP4/H.264, WebM, MP3, AAC, WAV…)।
